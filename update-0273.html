Hypixel SkyBlock 0.27.3: what is live and what is still on Alpha?

There are two separate things to track: the high-ping mining improvements that Hypixel rolled to the main network, and the larger Magic Find and Accessory Bag changes that were still being tested on Alpha in the latest official release-candidate post.

Status checked 15 November 2026. This is an unofficial, source-linked player guide, not an official Hypixel announcement.

LIVE ON MAIN NETWORK

Hypixel's 11 November patch notes say the high-ping mining and related fixes were rolled to SkyBlock.

0.27.3 RELEASE CANDIDATE #2

Hypixel's 12 November post places the second release candidate on the Alpha Network. Treat its larger changes as test information, not live rules.

Already live: the 11 November high-ping improvements

These changes are listed in Hypixel's main-network patch notes, separate from the remaining 0.27.3 Alpha testing:

  • Extra mining time can carry over from one block to the next, with the carry-over capped according to ping.
  • Breaking progress no longer resets just because you stop mining or switch to another block.
  • Mining Spread skips blocks that already have partial breaking progress.
  • Hard Stone in the Crystal Hollows can be instant-mined client-side.
  • Cactus can be harvested instantly client-side with the relevant tool.
  • Teleporting with certain items or using Ender Pearls no longer changes head rotation.
  • A short mining delay when switching to a mining tool was fixed.
Practical note: the Hard Stone change is specifically described for the Crystal Hollows. Do not assume the same client-side behavior applies to every mining area or block.

Read the official 11 November patch notes for the full wording and any later corrections.

Still being tested: 0.27.3 Release Candidate #2

Hypixel's 12 November announcement says the second release candidate is on the Alpha Network. It carries forward the first candidate's features, while excluding the high-ping improvements because those had already moved to the main network.

Magic Find changes in the candidate

  • Magic Find would affect all drops, rather than only drops with a base chance below 5%.
  • Above 100%, additional Magic Find would work like a Fortune-style chance for extra drops. Hypixel's example uses 150 Magic Find to guarantee twice an eight-item drop, with a chance at a third batch.
  • Loot share would use each player's own Magic Find instead of the killer's stat.
  • The proposed Magic Find cap is reduced from 900 to 500.
  • Hypixel says rare drop rates were broadly adjusted to account for the lower cap.
Do not treat these as final live values. The official post describes a release candidate on Alpha. Drop tables and numerical balance can still change before a main-network release.

Accessory Bag and inventory changes in the candidate

  • The Accessory Bag menu gives each accessory its own slot, with search, sorting, and in-game information about how to obtain or upgrade it.
  • The candidate also describes an Accessory Bag for the Rift.
  • Personal Compactors would use toggles for items stored in Sacks instead of individual item slots, and compact directly inside Sacks.
  • Separate Personal Compactor versions are proposed for core skill paths and Husbandry.

These are menu and quality-of-life changes that may affect how players organize accessories and automatic compacting. Wait for the final main-network notes before changing a long-term setup around them.

Economy changes to watch

The first release candidate also includes proposed changes to crop NPC sell values and the cost of Accessory Bag slot upgrades. Because the candidate is still an Alpha test in the latest official post, old guides and test screenshots should not be treated as current live prices.

What should players do right now?

  • If you mine: test the live block-progress carry-over and the Crystal Hollows Hard Stone behavior in-game. Results can differ with ping and location.
  • If you use Magic Find: do not rebuild your setup around the proposed 500 cap until the change is announced for the main network.
  • If you farm: check current NPC values in-game rather than copying crop prices from Alpha screenshots or older profit guides.
  • If you manage accessories or compactors: wait for final notes before reorganizing items based only on candidate screenshots.

For existing progression help, continue with the Mining Guide, Garden Guide, or beginner route. The Bazaar tool compares in-game virtual coin prices; its estimates are not guaranteed trade results.

Frequently asked questions

Is the full 0.27.3 update live on the main network?

The latest official 0.27.3 post checked for this guide describes Release Candidate #2 on the Alpha Network. The 11 November high-ping improvements are live, but the post does not announce a main-network release date for the remaining candidate features.

Are the Magic Find cap and Accessory Bag changes final?

No. They are described in a release candidate on Alpha. Check the final main-network patch notes before treating them as live mechanics.

Which mining changes are already live?

The 11 November patch notes list block-progress carry-over, progress persistence, Mining Spread skipping partially mined blocks, client-side Hard Stone mining in the Crystal Hollows, client-side Cactus harvesting, and related fixes.

Should I use Alpha prices for my current farming plan?

No. Alpha economy values are test information. Verify the current NPC value in the live game before using it in a farming estimate.
