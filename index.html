🧑 Live player profile

Hypixel API integration

Enter a Minecraft Java username. Skyblock Hub will ask its own backend for the player's public SkyBlock profile and display the available data here.

Player profile lookup is optional and requires a Hypixel developer key on the server. The item catalog, Bazaar prices, calculators and guides work without a key. Never paste an API key, Minecraft password or Microsoft login details into this page or into chat.

📊 Profile sections

When the API returns these fields and the player's in-game API settings allow access, the dashboard will show available Skills, Dungeons, Slayers, Collections, Pets, Inventory, Purse, Bank, Garden, Museum and other profile data.
