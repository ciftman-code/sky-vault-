Hypixel API integration

Enter a Minecraft Java username. Skyblock Hub will ask its own backend for the player's public SkyBlock profile and display the available data here.

Player profile lookup is optional and uses the site’s server-side Hypixel integration when available. The page checks service status automatically; it never asks visitors for an API key, Minecraft password or Microsoft login. The item catalog, guides and public tools remain available without profile access.
