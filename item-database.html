About the SkyBlock item catalog

This library is designed to make item research easier: search by display name or internal SkyBlock ID, filter by category or rarity, and open a card to inspect available item details. It is useful when learning crafting materials, farming resources, minion upgrades and collection items.

How item images work

The catalog reads each item's Minecraft material from Hypixel's public item resource and displays the matching vanilla Minecraft texture. Some SkyBlock items have custom resource-pack skins or special 3D models, so a base material image may not reproduce every custom appearance exactly. Missing textures fall back to a clear placeholder instead of showing a broken image.

Frequently asked questions

Does this database need an API key?

No. It uses Hypixel's public SkyBlock item resource, which does not require a personal player API key.

Why might an item's picture look different from a resource pack?

The public resource includes the item's base Minecraft material. Custom resource-pack textures and special models may differ from that base icon.

Does this page show live market prices?

No. The item resource describes catalog data. Use the Bazaar tool for current public market information and remember that prices can change.
