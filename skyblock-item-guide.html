Hypixel SkyBlock Items: A Beginner-Friendly Guide

Learn how item names, internal IDs, rarity, categories and textures fit together — then use the item library to search the public catalog.

What makes a SkyBlock item different?

In Hypixel SkyBlock, an item can have a display name, an internal identifier, a category, a rarity tier and a Minecraft material. Those fields serve different purposes. The display name is what players recognize, while the internal ID helps data tools identify the exact entry even when names are similar or change over time.

The material describes the underlying Minecraft item used as a base. A resource pack can replace the visual texture or model, so the material icon and the image you see with a custom pack may not always look identical.

How to read an item entry

  • Display name: the readable name shown in the catalog.
  • SkyBlock ID: the internal key used by game resources and tools.
  • Category: a broad grouping such as resource, pet, armor or material.
  • Rarity: the item's listed tier, when supplied by the resource.
  • Material: the base Minecraft material associated with the icon.
  • Extra data: available stats, requirements or NPC sell value, depending on the item.
Tip: Search by the internal ID if you know it. Search by a short part of the display name if you are exploring.

Understanding rarity tiers

Rarity is a useful label, but it is not a complete measure of how useful an item is. A lower-tier resource can still be important for a recipe, collection, upgrade or progression milestone. Compare the item purpose and the activity you are preparing for, rather than relying on rarity alone.

Some entries can use special rarity labels. If a field is missing from the public resource, the catalog leaves it blank rather than guessing.

How to research materials

  1. Search the item library. Enter a display name or internal SkyBlock ID.
  2. Filter the results. Narrow the list by category or rarity to make a large catalog easier to browse.
  3. Open an item card. Review its available category, rarity, ID and resource fields.
  4. Check related tools. Use the Bazaar explorer for current market data or the Craft Flip calculator for a recipe estimate.

Do item images always match the game?

The public item resource supplies a base material, and SkyBlock Hub uses that material to show a Minecraft texture. Custom resource packs can use a different texture or model, and some items have special appearances. The catalog explains this rather than presenting every base icon as an exact custom-pack render.

Do you need an API key?

No personal Hypixel API key is needed for the public item catalog or the public Bazaar resource used by the companion tools. Player-specific profile lookup is a separate feature and may require server-side configuration. Never share account passwords or API secrets with a website or in chat.

Frequently asked questions

Can I search with an internal ID?

Yes. The item database searches both the display name and the SkyBlock ID.

Why is an image different from my resource pack?

The catalog uses the base Minecraft material texture. A custom pack can replace the texture or model.

Are NPC values and market prices the same?

No. An NPC sell value is a game resource field; Bazaar market prices are player-market data and can change.

Is SkyBlock Hub an official Hypixel site?

No. It is an unofficial fan-made companion and is not affiliated with Hypixel or Mojang.
